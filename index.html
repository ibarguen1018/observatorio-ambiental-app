Mapa de estaciones

Estación oficial de DAGMA y observatorios comunitarios tipo Davis, con mediciones en vivo de calidad del aire y clima obtenidas por API REST — no son valores simulados.

Cargando datos en vivo de las 4 estaciones…
Buena Moderada Dañina (sensibles) Dañina
Interoperabilidad de datos: las 4 estaciones se modelan como una capa GeoJSON y las mediciones (PM2.5, PM10, ozono, NO₂, AQI, temperatura, humedad) se consultan en vivo contra la API REST pública de Open-Meteo (aire: Copernicus CAMS; clima: modelos meteorológicos), sin necesidad de clave. El mapa base usa teselas OpenStreetMap. Cuando DAGMA y los observatorios comunitarios publiquen sus propios servicios OGC (WMS/WFS) y feeds IoT de sus estaciones Davis, estas capas simuladas por geolocalización se reemplazan por las oficiales sin cambiar la interfaz. El ruido ambiental queda pendiente de integración: hoy no existe una API pública de sensores acústicos para Cali.
